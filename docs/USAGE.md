# 使用说明

## 截图记账

首页选择账单截图，等待本地 OCR。单笔进入核对页，多笔显示独立交易列表。核对金额、商户、收支类型、时间后确认入账；也可全部保存为待确认。余额、可用额度、日报和月度统计不作为交易金额。

## 消息与权限

设置中分别控制微信、支付宝、银行 App 通知、银行短信，业务开关默认开启。通知记账需要系统“通知使用权”，短信需要“接收短信”权限。只有新收到的短信参与处理，不读取历史短信。验证码、营销、待还款提醒和失败/待支付消息会过滤。自动捕获的记录先进入待确认，不直接计入汇总。

银行默认按常见包名、应用名称识别；未识别的银行可在设置中补充包名。小米等系统可能需要允许自启动并调整后台电池限制。

“微信支付卡片读取”为可选系统无障碍服务。开启后只针对当前微信支付、收款助手和银行公众号金融页面上的可见卡片，不自动点击、不发送消息、不读取未打开的历史记录。当前版本仍需真实微信页面验证。

## 导入与导出

首页选择“导入流水 / 小米记账文件”。导入前会展示有效、跳过、已存在和新增条数，核对后确认。

| 格式 | 支持范围 |
|---|---|
| 微信 / 支付宝 CSV、XLSX | UTF-8、GB18030、交易号去重；排除未支付/失败、按导出文件标记排除内部流转 |
| 小米记账六列 XLSX | 账单日期、记账分类、分类子类、收支类型、备注、金额；支持导入导出 |
| 银行 CSV、XLSX | 日期、带正负号交易金额或借方/贷方金额、对手、摘要；暂只计人民币 |
| 招商银行 PDF | 文本型“交易流水”模板；金额列与余额列分开提取 |
| JSON | 设置中导入/导出完整账本，包含待确认、来源和原始文字 |

加密 ZIP 请先解压；旧 XLS 请转为 XLSX。单文件上限 20 MB，记录上限 50000 条，PDF 上限 100 页。

退款作为收入保留，用于与原支出对照。银行流水包括信用卡还款、理财转入转出等实际账户流动；其统计口径与支付消费账单不同。不同渠道导入相同期间可能重复计账，请人工核对。

小米导出仅包含已入账记录。完整迁移使用 JSON。首页显示最近 500 条，汇总与导出包括全部记录。卸载前务必导出备份。
