# 数据与权限

- 截图 OCR 使用随安装包提供的 ppocr-rs WASM 模型，在本机执行。流水解析同样在本机完成。
- 无登录、云同步、遥测、远程 OCR 或远程账本接口。未集成广告或分析 SDK。
- 账本保存在应用私有 SQLite 中。卸载清除数据；系统自动备份关闭，可由用户导出 JSON/XLSX。
- 截图与导入导出文件使用 Android 系统文件选择器；应用不申请整个存储空间的读取权限。
- `INTERNET`：WebView 通过仅绑定 127.0.0.1、带随机路径的本地静态服务加载模型与资源。没有远程业务数据接口。
- 通知使用权：接收系统通知后，只处理所启用的金融来源与交易规则；交易文字保存于待确认账单。
- `RECEIVE_SMS`：用户授权后接收新的银行交易短信，不申请 `READ_SMS`，不读取短信历史。
- 可选无障碍服务：限定微信包名，识别金融助手页面可见交易卡片；不自动点击或发送信息。
- JSON 备份包含原始交易文字，属于敏感个人数据，请自行妥善保管和分享。

开源仓库及公开测试不包含用户账单、截图、短信、SQLite 数据库或签名私钥。
